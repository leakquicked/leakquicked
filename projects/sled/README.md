# След — журнал расследования

Небольшое локальное веб-приложение для учебного разбора журналов безопасности. Оно собирает события в временную линию, помогает искать совпадения по узлу, адресу и учётной записи, хранить заметки аналитика и выгружать результат расследования.

## Запуск

Откройте [index.html](./index.html) в современном браузере. Сборка, сервер и установка зависимостей не нужны.

## Возможности

- Импорт JSON-массива, JSONL/NDJSON и CSV.
- Вставка данных прямо в форму.
- Поиск по событию, узлу, IP-адресу, субъекту, источнику и идентификатору MITRE ATT&CK.
- Фильтры по уровню и источнику.
- Карточка события с сопоставлением записей по общему узлу, адресу или субъекту.
- Экспорт полного набора в JSON и сводного отчёта в Markdown.
- Заметки аналитика сохраняются в локальном хранилище браузера.

## Формат записей

Распознаются распространённые варианты названий полей:

| Поле приложения | Поддерживаемые имена |
| --- | --- |
| Время | `time`, `timestamp`, `@timestamp`, `date` |
| Уровень | `severity`, `level`, `priority` |
| Событие | `event`, `name`, `action`, `message` |
| Узел | `host`, `hostname`, `device`, `computer` |
| Адрес | `ip`, `src_ip`, `source_ip`, `client_ip` |
| Источник | `source`, `product`, `service`, `log_source` |
| Субъект | `actor`, `user`, `username`, `account` |
| MITRE ATT&CK | `mitre`, `technique`, `mitre_id` |
| Описание | `summary`, `description`, `details` |

Пример JSON:

```json
[
  {
    "time": "2025-03-18T08:42:11Z",
    "severity": "high",
    "event": "Неудачная аутентификация",
    "host": "workstation-17",
    "ip": "192.0.2.14",
    "source": "Windows",
    "actor": "analyst@example.test",
    "mitre": "T1110",
    "summary": "Синтетический пример события."
  }
]
```

Поддерживаемые значения уровня: `critical`, `high`, `medium`, `low`, `info` и русские эквиваленты. Если уровень неизвестен, запись отображается как информационная.

## Конфиденциальность и ограничения

Приложение не отправляет журналы на сервер: обработка выполняется в браузере. Заметки сохраняются через `localStorage` этого браузера. Экспортируйте данные только в место, которому доверяете, и не загружайте реальные персональные данные в публичную копию проекта.

Синтетический набор нужен только для демонстрации интерфейса. Сопоставление событий основано на совпадении полей и не является детектированием угроз. Приложение не заменяет SIEM, EDR или экспертное расследование; автоматический вердикт не формируется.
