## Engineering principles

- Prefer local processing and data minimization where practical.
- Use synthetic or documentation-range data in demonstrations.
- Never commit API keys, passwords, private logs or personal data.
- Document what a tool does, what it does not do, and what permissions it needs.
- Treat heuristic findings as leads for review, not as proof of compromise or vulnerability.
- Keep educational projects clearly distinguished from production security products.
